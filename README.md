# SRN Download Manager

Windows and Android release downloads, application source and browser companion.

**Website:** https://srn-download-manager.pages.dev/

[Download version 1.30.0](https://github.com/Vicky-32/SRN-Download-Manager/releases/tag/v1.30.0)

The release includes the Windows installer, Android 10+ ARM64 APK, other-PC setup
kit, Chrome/Edge companion 1.6.0 ZIP, exact application source ZIP and SHA-256 sums.
The Android APK has passed build/signature/alignment checks; physical-device
installation of this release remains unverified. Browser installation is manual.

SRN application source is GPL v3. The versioned source ZIP contains build/patch
scripts, notices and dependency provenance notes. Bundled engines carry their
own licenses. See [notices and engine source inventory](https://srn-download-manager.pages.dev/notices.html)
and the source ZIP's compliance directory for documented remaining engine-source
coverage gaps. No complete transitive corresponding-source claim is made.

Download supported content you own or are authorized to save, subject to platform
terms. DRM and private/restricted access-control bypass are unsupported.

Windows 1.30.0 provides an optional pinned signed update feed. In Settings → App
updates, select **Use SRN official releases**, then **Check for updates**. Startup
checks are separately opt-in. The signed feed is distinct from Windows publisher
Authenticode signing, which remains pending a trusted certificate.
